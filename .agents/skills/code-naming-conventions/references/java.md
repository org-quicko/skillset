# Java naming conventions

- Use `PascalCase` for classes, interfaces, enums, annotations, and records.
  Use `camelCase` for variables, parameters, fields, and methods.
- Use `UPPER_SNAKE_CASE` for constants. Ordinary immutable local values remain
  `camelCase`.
- Use lowercase for Java packages and their folders. Separate words and year
  numbers with underscores: `income_tax`, `house_property`, `ay_2026`, and
  `ty_2026`.
- Match a source filename to its public type: `TaxReliefEngine.java`. Add
  `Test` for a test file: `TaxReliefEngineTest.java`.
