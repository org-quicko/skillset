# 12 — Delete a Skill

**What to build:** An Admin removes a Skill for good — a mistake, or something obsolete. This is the one irreversible action in the Registry, so it asks for deliberation and is withheld from writers.

**Blocked by:** 04 — Publish a Skill from the web interface.

**Status:** ready-for-agent

- [ ] Deleting removes both the Skill's row and its Artifact.
- [ ] Deleting is permitted to Admins and refused to readers and writers.
- [ ] The web interface requires the Skill's name to be typed before it will delete.
- [ ] A deleted Skill disappears from the list and from search, and its page and its download stop working.
- [ ] The name becomes available for publishing again immediately.
- [ ] Deleting a Skill whose Artifact was never uploaded still removes the row rather than failing.
